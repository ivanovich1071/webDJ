# Сервис по доставке еды

**Технологии:** Python, Django, PostgreSQL, HTML, CSS, JavaScript

## Описание
Веб-приложение для управления заказами на доставку еды. Пользователи могут просматривать меню, оформлять заказы и отслеживать их статус. Администраторы управляют товарами, заказами и анализируют статистику.

## Основной функционал
- **Пользователи:**
  - Просмотр меню с фильтрацией.
  - Регистрация, авторизация.
  - Оформление и отслеживание заказов.

- **Администраторы:**
  - Управление блюдами и заказами через Django Admin.
  - Анализ статистики продаж.

## Результат
Демонстрация навыков работы с Django, реализации CRUD-операций, авторизации и управления данными.
